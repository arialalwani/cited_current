# Procedure to Update Address in Aadhaar Online

## Steps to update address online using a proof of address
1. Visit the myAadhaar portal and log in with the Aadhaar number and the OTP sent to the registered mobile number.
2. Select the Address Update option and choose Update Aadhaar Online.
3. Enter the new address exactly as it appears on the proof of address document.
4. Upload a clear scan of a valid Proof of Address document from the UIDAI list.
5. Pay the applicable fee online, if any, and submit the request.
6. Note the Update Request Number (URN) to track the status.

## Common reasons an address update is rejected
Requests are rejected when the address entered does not match the uploaded document, when the scan is unreadable, or when the document is not in the accepted list. A rejected request can be submitted again with a corrected document.
