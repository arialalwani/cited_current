# Photograph and Signature Specifications for OCI Applications

## Photograph specifications
| Requirement | Specification |
|---|---|
| Shape | Square; height and width must be equal |
| Pixel size | Minimum 200x200, maximum 1500x1500 |
| File format | JPEG |
| File size | 10 KB to 1 MB |
| Background | Plain light-coloured or white, no borders |
| Face | Full face, front view, eyes open, without dark glasses |

## Signature specifications
| Requirement | Specification |
|---|---|
| Aspect ratio | 1:3 (height:width) |
| File format | JPEG |
| File size | 10 KB to 1 MB |
| Signature type | Signed with a black or blue pen on white paper |
